# Práctica 1 – Creación de Clases y Encapsulamiento en PHP

## Objetivo
Aplicar los fundamentos de la Programación Orientada a Objetos en PHP mediante la creación de una clase que utilice encapsulamiento, constructor y métodos de acceso.

## Descripción de la clase
Se creó la clase `Usuario`, la cual contiene dos atributos privados: nombre y correo.  
La clase implementa un constructor para inicializar los valores y métodos getters y setters para acceder y modificar los datos de manera controlada.

## Instrucciones de ejecución
1. Copiar la carpeta `practica-1` dentro del directorio `htdocs` de XAMPP.
2. Iniciar Apache desde el panel de control de XAMPP.
3. Abrir el navegador y acceder a: http://localhost/desarrollo-web-avanzado-fimaz-uas/parcial-1-poo/Practica-1/index.php
4. Verificar que los datos del usuario se muestren correctamente en pantalla.
